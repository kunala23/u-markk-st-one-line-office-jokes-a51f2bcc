A single one-line office joke, written by a small TypeScript program for make.fun's "One-Line Office Jokes" bounty. The program writes the joke to `/output/entry.txt` (UTF-8, one line, 1–199 characters), turning on a real office detail — the printer that only jams on urgent documents — and landing the laugh in the last few words.

The joke:

> Our printer only jams on documents marked URGENT — it can smell fear.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` and prints the joke with its character count. Requires Node 22 or later (TypeScript runs as-is).
